# Round 3: remaking the weak examples

October 2026. Three fresh Claude Opus agents, docs only, each remade one example that looked like slides
(data story, vertical short, code explainer) and kept a friction log. All three results replaced the old
examples. Their logs drove these engine changes:

| Friction | Fix |
|---|---|
| Timeline lost `translate(-50%)` centering when the element was hidden on the first rendered frame (snapshot and still differed) | The timeline reads the transform as written (`computedStyleMap`), not the resolved matrix |
| Two timelines on one element multiplied their values | Values are merged per element; the tween that started last in video time wins |
| `gm.path.travel` did nothing on SVG shapes; `.progress(t)` ignored easing at load time | SVG shapes travel too; stops and easing are set up at once |
| `gm.burst` timing was clip time with no warning; could not sit behind or come from an element | `global: true`, `from: '#el'`, `behind: '#el'`, and a warning when it fires off screen |
| Syncing to music meant waiting for audio analysis | `gm.beat(n)` / `gm.bar(n)` from `<html data-bpm …>`, printed by `givemotion audio` |
| `{{data.…}}` undocumented; no data gave an empty video with no warning | Documented; `data.json` next to the HTML is used by default; `data-missing` warning |
| Missing `<gm-include>` only showed as a contrast warning; `../blocks` refused | `include-not-found` error; includes may live in a parent folder |
| Script errors had no line; a failed script caused misleading pacing warnings | File and line, the line's text, a hint for built-in names like `top` |
| A shape on top of text was not caught | `text-covered` warning (partly hidden for 0.3 s or more) |
| One camera move gave 90 warnings, one per code token | Issues with the same problem at the same times are grouped under their parent |
| No way to say a crop is on purpose | `data-check="crop-ok"` now silences it; the camera-world default still warns |
| Camera `padding` units unclear; too big a value zoomed out to nothing | Documented as screen px; clamped with a warning |
| Captions left one word alone, split across commas, ignored the vertical safe zone | Balanced paging that prefers commas; `offset` (420 px on vertical by default), `weight`, `upper` |
| Code window had no way to target a line or a part of a line | Every line is `.gm-line[data-line]`; `highlight`, `focus`, `gutter`, `grow`; `⟦…⟧` marks a range |
| Counting dropped zero padding and used a hyphen for minus | Number format of the page text is kept; real minus sign |
| No view of the rhythm | `check` starts with a motion strip, one mark per half second |
| The first frame was empty and nothing said so | `empty-start` warning; the default sheet includes frame 0 |
